# Bando — Abandoned Industrial

Original map made for fpv-sim by the fpv-sim contributors. Licence: GPL-3.0-or-later, the same as
the rest of the repository (full text: `LICENSE` at the repository root).

This package is the reference port of the procedural TypeScript map `bandoMap()` in
`src/maps/maps.ts` to the fpvsim-map v1 format (`docs/MAP_FORMAT.md`). `tests/mapFormat.test.ts`
checks that both produce the same terrain, collision primitives, trees, wake zones and spawn.
No third-party assets.
